# Оно тебе надо

Одностраничный сайт аукциона вещей, в которые никто не верил. Учебный проект Яндекс Практикума.

[Репозиторий проекта](https://github.com/Saakoz14/ono-tebe-nado)

## Превью сайта

![Оно тебе надо — главная страница аукциона](./ono-tebe-nado-preview.png)

## Возможности

- Главный экран с обложкой аукциона.
- Карточки лотов и раздел об аукционе.
- Навигация по секциям и контактная информация.

## Технологии

HTML5, CSS3, Grid Layout, Flexbox и локальный шрифт Raleway.
